# Offline audio (Stage 5)

* Audio is **optional** and never part of the Starter Pack. Each lesson shows its size first and is downloaded on request into
  IndexedDB (`audio` store, as a Blob). Nothing is precached by the service worker.
* A download is stored only if the full file arrived with an `audio/*` content type and the exact expected byte size.
  An interrupted download stores nothing and is retried from the start (files are small).
* Playback uses a plain `<audio>`/`Audio` element on a Blob URL, so it works with no network and no text-to-speech.
  Smart Listen (browser speech synthesis) is unchanged; starting one pauses the other.
* The only file today is `public/audio/en/rice-planting-demo.m4a`: a **computer-voice English demonstration** reading existing Rice guide
  text, generated by `scripts/make-audio-fixture.ts`. It is labelled as a demonstration everywhere. It is not a lesson.
* **Kpelle, Bassa and Mano have no recordings.** They are listed in `src/data/audioLessons.ts` as "awaiting recordings" so the UI says so.

## Adding a real recording
1. Put the file in `public/audio/<code>/` (mono, ~24-48 kbps).
2. Add an entry to `AUDIO_LESSONS` (`kind: 'lesson'`, `synthetic: false`, real `bytes` and `durationSec`, the transcript actually spoken,
   `reviewedBy` for the native-speaker reviewer) and set the language `status` to `'available'`.
3. The "Listen Offline" block appears automatically on the guide whose id matches `guideId` (e.g. `crop:rice`).
